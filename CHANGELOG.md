# Changelog

## 2.0.0

- Rebuilt the original plugin into configuration, core-action, UI, and focused Harmony-patch layers.
- Changed the default menu hotkey from F2 to M, added Insert as a recovery key, and added in-game rebinding.
- Removed the experimental Skip Winning Animation and Turbo controls; Auto is the only slot mode and defaults to off.
- Added configurable CloverLife-inspired QoL options for intro skipping, corpse completion, faster memory packs, automatic card flipping, and phase-dependent speeds.
- Added the camera-transition overshoot fix and a temporary safe 4x cap during payout/charm animations to prevent black screens.
- Added a searchable charm browser with owned/equipped/drawer/unlocked status, charges, equip, recharge, modifier selection, and confirmed discard.
- Added charm-slot add/set actions, corpse-piece equipping, free restocks, and dynamic charm/memory-card support.
- Added symbol-chance locks, automatic normalization to 100%, zero-value support, and a symbol coin-value editor.
- Added current-run information, seed copy, clearly described activation/charm/store luck editors, and confirmed Deadline-level/Deposit edits.
- Added Normal, Lucky, and persistent Custom presets with a larger in-menu explanation box.
- Added one-level Undo for the latest supported reversible numeric change.
- Fixed custom ticket values, one-unit additions, speed sliders, and the 5x animation-speed option.
- Added optional unlimited memory cards, phone actions, rounds/spins, pattern values, achievements confirmation, and strict input validation.
- Added a dedicated searchable Memory Cards tab and support for stacking standard and Fusion-DLC card effects with the primary card.
- Removed the large-number/scientific-notation feature and other unused legacy files.
